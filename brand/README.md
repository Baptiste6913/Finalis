# Brand assets

Drop the official Finalis logo here as `logo.svg` (preferred) or `logo.png`, then run `python3 build.py`.
The build inlines it as a data URI into all three flavours (artifact, demo, local) and the page shows it in
the app bar and in the submission modal. Without a file, the page shows the "finalis" wordmark in text.

Keep the height around 26 px in the app bar: a horizontal logo about 110 x 26 px looks right.
